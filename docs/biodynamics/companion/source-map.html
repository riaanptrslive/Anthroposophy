Edition and reference system

Rudolf Steiner, What Is Biodynamics? A Way to Heal and Revitalize the Earth. Seven Lectures, SteinerBooks. Introduction © 2005 Hugh J. Courtney. Edited by Marcia Merryman Means. The supplied PDF contains 135 capture pages; these are not printed page numbers.

Source cycles: GA 136 lectures 1–2 (April 3–4, 1912); GA 230 lectures 7–8 (November 2–3, 1923); GA 327 lectures 4–6 (June 12–14, 1924). Page 3 supplies translator and editor credits. This is a selection, not the complete Agriculture Course.

The inventory was drafted before the page lessons. The text extraction was read throughout; all page images were screened for highlights and layout, with highlighted passages inspected at full size. The private book and its page images are not reproduced here.
